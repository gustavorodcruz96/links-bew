# BEW Store Links

Página de links da BEW Store recriada em Vite JS.

## Scripts

- `npm run dev`: inicia o servidor local.
- `npm run build`: gera a versão estática em `dist/`.
- `npm run preview`: pré-visualiza o build localmente.

## Links
